## Building the classifier

### Minimum Percentage Split Value resulting in 0 incorrectly classified instances

Let p ∈ [0, 1] be the minimum percentage split value, which gives 0 incorrectly classified instances. For the given dataset with the chosen attributes, if the dataset is split into 92 % Training data and 8 % Test data for the induction of the supervised learning model, the test data will be classified with 0 errors. Hence, the value of p is 0.92. This might work well for the dataset, which the model is trained on. However, p is not a viable value for splitting the instances.
The model created with the given dataset and the chosen attributes is too complex and tends to overfit other datasets. That is, the model reacts too sensitive to low variance. Overfitting ocurrs, if, in addition to the patterns, the model learns the noise in the training data, too. In general, the more data is used for training (p -> 1), the higher the risk for overfitting.
In contrast, if the model is trained on too little data (p -> 0), the model tends to underfit new datasets. That is, it cannot properly identify the patterns in the data, because it is too simple.
