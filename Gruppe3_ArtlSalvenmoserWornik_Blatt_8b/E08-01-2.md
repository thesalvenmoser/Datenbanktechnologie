## Data Analysis and Cleaning

### Data Cleaning

The attributes feathers, milk, backbone, airborne, predator, legs, fins, and tail are the only ones needed to build a classifier which returns the type for a given instance. All the other attributes can be removed. Otherwise, the algorithm will prune the nodes created with these attributes based on the (low) information gain ratio.
